## Current public documentation and request fields

**TomTom.** GET `https://api.tomtom.com/routing/1/calculateRoute/{lat},{lon}:{lat},{lon}/json` accepts `travelMode=car`, `routeType=fastest`, `traffic=true`, `departAt=now` and `computeTravelTimeFor=all`. `routes[0].summary.travelTimeInSeconds` is seconds and `lengthInMeters` is metres. `noTrafficTravelTimeInSeconds` is an explicit optional baseline; do not relabel the ordinary estimate or an off-peak observation as traffic-free. Geometry is the leg point sequence. The documented `traffic=false` behavior still involves historical speeds and is not interchangeable with the explicit no-traffic field. The public Routing allowance is now 20,000 requests per month; 2,500 per day is an older offer, not the current published plan. Individual legacy account entitlements were not independently audited. Sources: [Calculate Route](https://docs.tomtom.com/routing-api/documentation/tomtom-maps/v1/calculate-route), [pricing](https://docs.tomtom.com/pricing), [migration](https://docs.tomtom.com/platform/documentation/status-and-support/migrating-to-mytomtom).

**2GIS.** POST `https://routing.api.2gis.com/routing/7.0.0/global?key=REDACTED` uses two `points` with `type=stop`, `lon` and `lat`, `transport=driving`, `route_mode=fastest`, and `traffic_mode=jam`. A successful route is `result[0]`; `total_duration` is seconds and `total_distance` is metres. The returned `algorithm` description can say `with traffic jams`; it does not disclose the mathematical route solver. Detailed geometry is returned within maneuver paths as WKT. No paired no-traffic duration was identified, so that column stays missing. The documented one-time demo lasts one month and provides 1,000 Routing units in total. The account UI was observed by the setup agent to show 5 units per minute; the subscription throughput must not be substituted for this demo limit. Alternatives and batching do not turn several OD routes into one billed route. Sources: [overview](https://docs.2gis.com/en/api/navigation/routing/overview), [reference](https://docs.2gis.com/en/api/navigation/routing/reference/routing), [demo keys](https://docs.2gis.com/en/platform-manager/subscription/keys), [pricing](https://docs.2gis.com/en/platform-manager/subscription/pricing).

**openrouteservice (ORS).** The current POST host is `https://api.heigit.org/openrouteservice/v2/directions/driving-car/geojson`, with the key in the `Authorization` header. The body contains `coordinates` in longitude-latitude order, `units=m`, and `instructions=false`. Read `features[0].properties.summary.duration` in seconds, `.distance` in metres, and `features[0].geometry.coordinates`. The public hosted API does not use live traffic. No-traffic duration is left missing because the response does not provide a separate paired baseline. The Standard Directions allowance is 2,000 requests in a 24-hour window and 40 in a rolling minute; daily exhaustion and minute throttling are documented as HTTP 403 and 429 respectively. The old `api.openrouteservice.org` host is being retired. Sources: [API reference](https://giscience.github.io/openrouteservice/api-reference/), [limits](https://giscience.github.io/openrouteservice/frequently-asked-questions), [traffic statement](https://ask.openrouteservice.org/t/isochrone-trafic-data/7875), [host migration](https://ask.openrouteservice.org/t/deprecating-api-openrouteservice-org-in-favour-of-api-heigit-org/7912).

## Storage, numerical extracts and public redistribution

**TomTom is blocked for this study.** The current Portal Terms section 11.4 restricts storing Results to permitted client caching under the response cache headers. Section 11.6.1 restricts secondary or derived databases. Section 11.6.10 requires prior written approval for comparison or benchmarking with similar competitor products. No numerical-only research exception was found. Removing route geometry does not resolve the explicit comparison restriction. A separate written agreement may change these terms, but none was inspected or obtained. Source: [Portal Terms and Conditions](https://docs.tomtom.com/legal/terms-and-conditions). The text is client-rendered; the public page's referenced legal component was read as static text, not executed.

**2GIS rights remain unresolved for the Kazakhstan demo.** The public WebAPI offer names Routing API methods and restricts extracting, storing and reusing product information outside its terms. The relationship between that Russian offer and this Kazakhstan demo account has not been verified. Platform ID and Platform Manager terms also point to separate service conditions; a key-management agreement alone is insufficient to settle Routing data rights. No explicit authorization for permanent public numerical extracts or geometry was found. This is a specific permission gap, not a claim that every Kazakhstan use is prohibited. Sources: [WebAPI offer](https://law.2gis.ru/offer-license-agreement-webapi), [Platform ID](https://law.2gis.ru/en/platform-id), [Platform Manager](https://law.2gis.ru/en/platform-manager).

## Design consequence and interpretation

The versioned configuration enables only ORS. It plans three full pilot cycles over 20 fixed OD pairs, followed by four rotating routes per nominal 15-minute slot for 48 hours. This is 60 pilot requests and 768 nominal scheduled requests, plus a small verification allowance, bounded by a 900-request study budget. Each individual route has a nominal 75-minute revisit, not a 15-minute revisit. Actual timestamps determine coverage; late or missed slots are not backfilled.

The TomTom–2GIS question and predeclared expectations remain prospective. ORS-only records can test extraction, timing, completeness and reproducibility, but they cannot estimate between-provider disagreement or evening traffic effects. No routing solver is attributed to a commercial service without a specific source. The familiar road-graph model and sums of edge travel times are explanatory abstractions, not recovered proprietary implementations.
